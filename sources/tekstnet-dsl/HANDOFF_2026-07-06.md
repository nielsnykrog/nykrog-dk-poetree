### 3. Author bug fix in parser

**Problem**: Variant B (single-poem) pages like `andersen-hc_til-deres-majestaet-enke-dronningen` and `ploug-c_til-de-gamle` were being written with `author.name="anonymous"` because Tekstnet's publication metadata block on these pages only has **editorial credits** (Hovedredaktør, Redaktion), not the literary Forfatter.

**Fix in `parser.py`:**
- `parse_publication_page` now returns `forfatter_present=True/False`.
- New helper `literary_author_from_publication(pub_meta, html)` recovers the author from the page's `<title>` tag or active breadcrumb when the publication-page `Forfatter` is missing.
- `parse_poem_page` now uses this helper. Verified working:
  - `andersen-hc_til-deres-majestaet-enke-dronningen` → `author="H.C. Andersen"`
  - `ploug-c_til-de-gamle` → `author="Carl Ploug"`
